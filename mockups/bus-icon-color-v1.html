バスアイコン 色・輪郭 改善案

ご要望: 本体色はグリーンをやめて実車に近いグレー(あまり目立たせない)。窓の色(混雑度)は引き続き踏襲。 輪郭だけで一階建て/二階建てがはっきり分かるようにする。

現行(参考、緑の本体色)
単一・空席
単一・満席
二階建て
Pattern 1 — グレーに置き換えのみ(形は現行のまま)
本体色だけを緑からグレーに変更。輪郭・窓配置は現行と同じ(アスペクト比のみで単/二階を区別)。
単一・空席
単一・満席
二階建て
Pattern 2 — グレー+輪郭線
本体を少し薄いグレーにして、輪郭線(少し濃いグレー)を追加。輪郭がくっきりして形が分かりやすくなる。
単一・空席
単一・満席
二階建て
Pattern 3 — グレー+輪郭線+二階建てを「段差」で表現
二階建ては上段を少し幅を狭くして「段差」をつけ、実車のシルエットに近づける。アスペクト比だけでなく 輪郭の形そのもので一階/二階建てが一目で分かるようにする。
単一・空席
単一・満席
二階建て(段差あり)
Pattern 3 拡大表示(二階建ての段差を確認)
